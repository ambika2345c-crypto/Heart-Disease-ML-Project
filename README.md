# Heart Disease Prediction using Machine Learning

## Project Overview

This project uses Machine Learning algorithms to predict whether a person is likely to have heart disease based on different health-related attributes.

The main objective is to apply multiple Machine Learning algorithms to the same dataset, evaluate their performance, compare the results, and identify the best-performing algorithm.

## Dataset

The dataset used in this project is the **Heart Disease Dataset** obtained from Kaggle.

- Number of records: 270
- Number of features: 13
- Target variable: `heart disease`

The dataset contains attributes such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Serum Cholesterol
- Fasting Blood Sugar
- Resting ECG Results
- Maximum Heart Rate
- Exercise Induced Angina
- Oldpeak
- ST Segment
- Major Vessels
- Thal

## Machine Learning Algorithms

Three Machine Learning classification algorithms were applied:

1. **K-Nearest Neighbors (KNN)**
2. **Random Forest Classifier**
3. **Support Vector Machine (SVM)**

## Methodology

The following steps were performed:

1. Loaded the Heart Disease dataset.
2. Explored the dataset structure and columns.
3. Checked for missing values and duplicate records.
4. Cleaned and prepared the data.
5. Separated the input features and target variable.
6. Split the dataset into training and testing sets.
7. Applied feature scaling where required.
8. Trained three Machine Learning algorithms.
9. Made predictions using the test data.
10. Evaluated and compared the models.

## Evaluation Metrics

The performance of the algorithms was compared using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Results

The performance of all three algorithms is compared using the evaluation metrics generated by the Python program.

The algorithm with the highest overall performance is selected as the **best-performing model**.

The program also displays:

- Model comparison table
- Accuracy comparison graph
- Confusion matrices
- Classification reports
